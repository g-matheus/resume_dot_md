A estrutura que organiza seu currículo

Use a estrutura simples do Markdown e 3 tipos de tags para adicionar contexto ao seu conteúdo.

As tags são: [lang:] identifica o idioma de cada linha, [date:] informa o período e [level:] indica o nível da experiência.

Veja um exemplo:

# Michael Silva

## [lang: ptBR] Experiência
## [lang: enUS] Experience

### [lang: ptBR] Engenheiro de Software Staff | Big Tech Company
### [lang: enUS] Staff Software Engineer | Big Tech Company

[lang: ptBR] Liderei a migração de uma plataforma para microsserviços, reduzindo o tempo de deploy em 60%.
[lang: enUS] Led a platform migration to microservices, reducing deployment time by 60%.
[date: 2019-03..2024-06]
[level: Staff]
#, ## e ###
Organizam seu nome, as seções e títulos de experiência, projeto, etc.
[texto](link)
Deixa portfólio, LinkedIn, GitHub e outros projetos clicáveis no PDF.
[lang: ...]
Indica o idioma de cada linha. Para cada linha, adicione a mesma informação traduzida com outra tag de idioma.
[date: ...]
Mostra o período de uma experiência ou projeto.
[level: ...]
Mostra o nível daquela experiência.

Mais contexto para a IA. Mais clareza para o recrutador.

Dúvidas comuns

Preciso saber programar?

Não. Markdown (.md) é um formato de texto simples. Você pode escrever seguindo a estrutura indicada ou pedir para uma IA converter seu conteúdo.

Posso usar meu currículo em outros idiomas?

Sim. Use a tags de idioma para cada bloco de texto que possua tradução e escolha qual será usada naquela versão. Tags de idioma evitam inconsistência de traduções automáticas.

Isso funciona para recrutadores e para IAs de RH?

Sim. O PDF mantém uma estrutura consistente para facilitar a leitura automática, sem abrir mão de uma apresentação clara para recrutadores humanos.

Posso mudar o template depois?

Sim. O conteúdo fica separado da apresentação. Você pode testar diferentes templates sem reescrever seu arquivo.

Pronto para transformar seu currículo?

Comece pelo arquivo que você já tem. Em poucos passos, ele ganha uma apresentação profissional e uma versão adequada para a oportunidade.
